# Multilingual system (English / ಕನ್ನಡ)

CrimeLens uses **react-i18next** with JSON message catalogs — not Google Translate or browser translation.

## Files

```
apps/web/src/messages/
  en/  common.json dashboard.json analytics.json reports.json ai.json auth.json settings.json
  kn/  (Kannada equivalents)
apps/web/src/shared/i18n/   # i18n init, provider, LanguageSwitcher, locale persistence
services/api/app/core/i18n.py  # API-side strings for reports / advisor / explain
```

## Behaviour

- Language switcher in sidebar + top bar
- Instant client-side switch (no full reload, same route)
- Preference in `localStorage` key `cl_locale` + cookie
- `apiFetch` sends `X-CrimeLens-Locale` and `Accept-Language`
- Reports `generate` accepts `locale: en|kn` (bilingual flag reserved)
- Noto Sans Kannada font via `next/font`

## Usage

```tsx
const { t } = useTranslation("dashboard");
return <h1>{t("title")}</h1>;
```

Switch: `setAppLocale("kn")` from `@/shared/i18n/setLocale`.
